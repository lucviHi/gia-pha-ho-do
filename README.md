# Gia phả họ Đỗ

Website gia phả tĩnh, công khai và không yêu cầu đăng nhập.

## Bật GitHub Pages

Vào **Settings → Pages**, tại **Build and deployment** chọn:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Sau đó nhấn **Save**. Địa chỉ dự kiến: https://lucvihi.github.io/gia-pha-ho-do/
